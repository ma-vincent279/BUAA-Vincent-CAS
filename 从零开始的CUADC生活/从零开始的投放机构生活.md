## 一、为什么不用"直接扔"

投放机构可选方案：

| 方案 | 优点 | 缺点 |
|---|---|---|
| 纯重力（插销一拔就掉）| 最简单 | **不可控**：不知道什么时候掉的、抖一下可能自己掉 ✗ |
| 电磁铁 | 快 | 需要持续通电；断电就掉（危险）；**没有"已投放"的正反馈** |
| **PWM 舵机 / 电机驱动** ★ | **可控、可重复、有时序** | 需要机构、占一个通道 |

⇒ 我们选**受控机构**：**`AUX5` 通道 → 舵机/执行器 → 齿轮齿条 → 直线行程 → 放开载荷** ✓

**【经验/建议】** 比赛里"投下去"是硬要求（不投 = 0 分），
所以机构的首要指标是**可靠**，不是"精巧" ✓

## 二、PWM 怎么控制舵机

### 2.1 PWM 基础

舵机靠**脉宽**表示位置：

```
周期 通常 20 ms (50 Hz)
   │
   ├── 脉宽 1000 µs  →  一个极端位置
   ├── 脉宽 1500 µs  →  中间位置
   └── 脉宽 2000 µs  →  另一个极端位置
```

### 2.2 为什么本项目用 200 Hz 而不是 50 Hz

**【源码事实】** 我们从 `/fmu/in/manual_control_input` 发 `ManualControlSetpoint`，
**200 Hz** 发布。

**为什么**：这个数据要走 **RC 输入 → 混控器 → AUX5 引脚** 的路径，
而 RC 接收机（SBUS）的更新率约 **111 Hz** ⇒ **必须发得比它快，才能"盖住"接收机的值** ✓
（否则接收机的手动信号会覆盖我们的值 ✗）

### 2.3 需要的 PX4 参数配置【源码事实】

| 参数 | 值 | 作用 |
|---|---|---|
| `PWM_AUX_FUNC5` | **411** | AUX5 输出配置成舵机 |
| `PWM_AUX_MIN5` / `MAX5` | **900 / 2100 µs** | 允许的脉宽范围 |
| `RC_MAP_AUX5` | **Unassigned** | **解除遥控器对该通道的占用**，让 DDS 数据独占 |

> ⚠️ `RC_MAP_AUX5` 这条**很容易漏**：不解除的话，遥控器的摇杆会和我们的程序抢这个通道 ✗
> （见 `src/drone_drl/drone_drl/aux5_ramp.py` 的注释）

## 三、本项目的投放时序【源码事实】

### 3.1 aux5 值 → 脉宽

**【源码事实】** 代码里的映射是**线性的**：

```python
脉宽(µs) = 1500 + aux5 × 600
```

### 3.2 实际的三个值

| 动作 | `aux5` 值 | **脉宽** | 常量名 |
|---|---|---|---|
| **锁定（待机）** | `0.0` | **1500 µs** | `AUX5_LOCK` |
| **投放第 1 瓶** | `+0.83333` | **2000 µs** | `AUX5_DROP` |
| **投放第 2 瓶** | `−0.83333` | **1000 µs** | `AUX5_DROP2` |

> ⚠️ **注意：两瓶是往相反方向放的！** 第 1 瓶 →2000 µs，第 2 瓶 →1000 µs。
> 这与"**两瓶镜像挂载**"是一致的（见第五节）✓

### 3.3 投放时序

```
   时间 ──────────────────────────────────────────────►
   │
   │  锁定 1500 µs  ────┐
   │                    │  判据达标
   │                    ▼
   │              投放 2000 µs (第1瓶)  ← 保持 1.0 s (AUX5_DROP_HOLD)
   │                    │
   │                    ▼
   │              回到锁定 1500 µs
   │                    │
   │              爬升离开 (CLIMB) → 准备第 2 瓶
```

**【源码事实】** 投放脉冲保持 **1.0 s**（`AUX5_DROP_HOLD = 1.0`），之后回到 `AUX5_LOCK`。

**【经验/建议】为什么要保持 1.0 s**：
舵机/机构从"开始动"到"载荷完全脱开"需要时间（**齿轮齿条有行程、有摩擦**）。
**不发够时间，载荷可能没完全脱开** ⇒ 变成"投了但没掉" ✗
（我们从 ULog 里实测确认过脉冲是干净的：2000 µs 保持 1.099 s / 1000 µs 保持 1.001 s ✓）

### 4.2 推断的机构原理【待验证】

```
   舵机/电机  ──►  齿轮 (chilun)  ──►  齿条 (chitiao)  ──►  直线运动
                                                    │
                                                    ▼
                                          挡住 / 放开载荷
```

**为什么用齿轮齿条**（【经验/建议】）：
- **把旋转变成直线**，行程可控
- **重复性好** —— 机构动作一致性直接影响落点散布
- **能承受侧向力**：飞行中载荷会晃，直接舵机臂容易被推翻

## 五、载荷、重心与"投不准"的关系

### 5.1 载荷挂在哪【源码事实】

**两瓶挂在机身两侧**，而且**镜像**：
- **第 1 瓶（先投）在机体右侧**
- **第 2 瓶在机体左侧**

### 5.2 三个后果

| 后果 | 说明 |
|---|---|
| **① 落点 ≠ 飞机正下方** | 释放口相对**相机光轴**有偏移 ⇒ 必须补偿 |
| **② 两瓶的补偿符号相反** | 镜像 ⇒ 第 2 瓶补偿必须反号 |
| **③ 投放瞬间给飞机一个力矩** | 单侧卸掉载荷 ⇒ 飞机被推一下 ⇒ 判据要考虑这个扰动 |

### 5.3 【实测数据】真实踩过的坑：两瓶用了同一个补偿

早期代码给两瓶设了**同一个横向补偿**，结果"**第 2 投总偏左**" ✗

用 4 次实测落点反推**需要的**补偿：

| 瓶 | 需要的补偿 |
|---|---|
| 第 1 瓶（右）| **+9.8 ~ +12.8 cm**（均值 +11.3）|
| **第 2 瓶（左）** | **−7.2 ~ +2.3 cm**（均值 **−2.5**，**必须反号**）✗ |

⇒ **【经验/建议】机械不对称的东西，参数就必须分开** ✓

## 六、补偿：为什么落点会偏，怎么标定

### 6.1 补偿的物理含义

我们要控制的是"**载荷落点**"，但飞机上装的是"**释放口**"：两者差一个**固定机械偏置** `r`。

```
   瞄准点 = 桶的位置 + 补偿
              └── 让"落点"落在桶上, 而不是让"飞机"停在桶上
```

### 6.2 【源码事实】标定公式

```
固定机械偏置  r = 落点 − 飞机站位 − 本次补偿 − vxy × 0.5s

新补偿 = −r
```

| 项 | 从哪来 |
|---|---|
| `落点` | **卷尺实测**（两个带符号分量！）|
| `飞机站位` | 节点日志释放行的 `落点相对home` |
| `本次补偿` | 当次跑的补偿值（可以故意设成 0）|
| `vxy × 0.5s` | 载荷下落 1.2 m（约 0.5 s）期间飞机的水平漂移 |

⇒ **一飞两投就能闭式解出两瓶的 `r`** ✓

### 6.3 ⚠️ 当前补偿是**归零**的【源码事实】

| 项 | 状态 |
|---|---|
| `K_ZERO_COMPENSATION` | **True** |
| 原因 | **2026-10-12 换了相机画幅**（改 130° 原生画面）⇒ **旧的补偿是在旧相机模型下标定的，继续用会系统性偏掉** ✗ |
| 下一步 | **等实机首飞，用卷尺量出落点，重新标定** ⏳ |

### 6.4 测量协议（**别写"偏左下方"**）【经验/建议】

现场必须量**两个带符号分量**：

| 分量 | 正方向 |
|---|---|
| **沿航向** | 前 + / 后 − |
| **垂直航向** | 右 + / 左 − |

⇒ "偏左下方" 这种描述**没法算补偿** ✗（不知道偏多少、也不知道相对哪个轴）

## 七、地面测试（**拆桨！**）【经验/建议】

**飞之前一定要做地面测试**，验证整条链路：

```bash
# 在 ~/fly 上（系统 Python 即可）
ros2 run fly test           # 地面测试: ARM→检测→投放→循环
# 或专门的蓝本（只测舵机，不切 OFFBOARD）
ros2 run fly dj             # AUX5 PWM 三角波 (900~2100µs)
```

**【源码事实】** 本项目有专门的节点：
| 节点 | 用途 |
|---|---|
| `dj.py` | **AUX5 PWM 三角波测试**（900~2100 µs 来回扫，肉眼确认机构行程）|
| `test.py` | **地面测试**：ARM → 检测 → 投放 → 循环（不装桨）|
| `aux5_ramp.py` | AUX5 控制**蓝本**：解锁后 200 Hz 往复，**不切 OFFBOARD** |
| `ground_test_mission.py` | 不装桨原地验证 ARM→OFFBOARD→视觉检测→AUX5 投放**全链路** |

> ⚠️ **拆桨！** `ground_test_mission` 会切 OFFBOARD 让电机转 ✗

## 九、术语表

| 术语 | 意思 |
|---|---|
| **PWM** | 脉宽调制（用脉宽表示位置/速度）|
| **`aux5`** | PX4 手动控制消息里的一个通道值，范围 −1 ~ +1 |
| **`ManualControlSetpoint`** | PX4 的手动控制消息类型 |
| **SBUS** | 一种遥控接收机协议（更新率 ~111 Hz）|
| **行程** | 机构能移动的距离 |
| **机械偏置 `r`** | 释放口相对相机光轴（或瞄准点）的固定偏移 |
| **AUX5** | PX4 的第 5 个 AUX 输出通道 |
