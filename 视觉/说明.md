# 视觉 —— 相机与目标识别

这里放**跟视觉识别相关的一切**：相机模型、反投影、检测器、训练。

## 一、我们的相机

| 项 | 值 |
|---|---|
| 类型 | USB **单目**，装成**固定下视**（光轴朝机体下方）|
| 畸变 | **无畸变模型** |
| 画幅 | 16:9 |
| 标称视场 | **对角线 130°** |
| 处理分辨率 | **640 × 360**（1920×1080 全帧**缩放**，**不裁剪**）|

## 二、内参是怎么来的

**是算出来的，不是标定出来的**：

```python
FX = FY = (√(640² + 360²) / 2) / tan(65°) = 171.21 px
HFOV = 2·atan(320 / 171.21) = 123.70°
VFOV = 2·atan(180 / 171.21) =  92.87°
```

⚠️ **别把"对角线 130°"当成水平视场** —— 水平/垂直分别是 **123.70° / 92.87°**。

## 三、反投影（本项目最核心的运算）

```
地面偏移 = 像素偏差 × 高度 / FX
```

姿态修正由 `camera_pixel_to_level(cx, cy, pitch, roll)` 完成：先把像素反投影成
机体坐标系射线，再**去掉 pitch/roll**。

> **姿态项不能忽略**：`H · tan(pitch)`，在 `H = 1.2 m`、`pitch = 5°` 时约 **10 cm** ✗
> 有一趟实飞 pitch 达 4.2~5.6°，落点整体偏前 11~12 cm。

## 四、⚠️ 一条重要的踩坑记录（直径反推的 depth）

要按直径识别桶（15/20/25 cm），需除以深度抵消透视：`D = 像素边长 × depth / FX`

**关键在于用哪个"距离"**：

| 反推用的 depth | 最大往返误差 | 判定 |
|---|---|---|
| **垂直高度** ← 正确 | **0.00 cm** | ✓ 精确 |
| 斜距 `√(H²+r²)` ← 曾想改成这个 | **14.15 cm** | ✗ 破环 |
| `√(H²+r²)²/H` | 41.67 cm | ✗ 破环 |

`H=1.2 m`、偏心 `2.0 m` 时，15 cm 桶被斜距公式算成 **29.2 cm** ⇒
与目标记录差 14 cm ≫ 容差 3 cm ⇒ **门会把目标自己拒收** ✗

⇒ **已撤回**，并做成**回归护栏**写进离线验收 ✓

**教训**：**反投影模型必须与正投影模型一致**。
"物理上更对"的公式，如果和检测器用的不一致，反而会错 ✗
