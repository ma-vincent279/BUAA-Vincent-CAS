# 提案 3 · 机械资料补全

> **状态**：⏳ **待补** —— 这件事**不难，但拖一届就没人说得清了**。

## 现状

**【源码事实】** 我们辛苦攒下的机械设计，仓库里只有：

```
结构/投放机构/CATIA/
├── 投放机构/    齿轮 (chilun) / 齿条 (chitiao) / 电机架 (dianjijia3)
├── 板件/        发射架上板 / 导向环
├── 图传/        相机外壳
└── 连接件/      发射架连接 / 10mm 管 / 16mm 管 / 通用连接件 ×3
```

**12 个 `.CATPart` 零件文件**（共 4.2 MB）。

## 缺什么

| 缺的 | 为什么需要 |
|---|---|
| **`.CATProduct`（总装图）** | 现在**只有零件，没有装配关系** ⇒ 不知道零件之间怎么装 ✗ |
| **STEP 导出**（`.step`/`.stp`）| 让**没有 CATIA** 的人也能看/改（FreeCAD / SolidWorks / Fusion360 都能开）|
| **STL / 3MF** | 直接送打印 |
| **二维加工图**（含尺寸公差）| 替换零件时要用 |
| **实物照片** | 文档里最有用的东西 |
| **释放口相对相机光轴的实测偏移** | 补偿标定的起点（见 [`../提案1_落点补偿标定/`](../提案1_落点补偿标定/)）|
| **机构行程 / 保持力 / 循环寿命** | 判断可靠性 |

## 提案

### 拿到实物后，第一件事做这些（半天）

1. **拍照** —— 装配好的机构，多角度，至少 6 张
2. **量尺寸** —— 关键尺寸用卡尺量并记下来
3. **导出 STEP** —— 如果你的电脑能开 CATIA：
   `文件 → 另存为 → .step`（每个零件 + 总装各一份）
4. **量一次静态偏移** —— 把飞机摆平，量"释放口在地面的投影"与
   "相机光轴在地面的投影"的距离（**两个方向都要量**）
5. **全部提交进这个仓库**

### 关于打开 CATIA 文件

| 工具 | 能开吗 |
|---|---|
| **CATIA**（原厂）| ✅ 完整编辑 |
| **eDrawings**（免费）| ✅ 只读查看 |
| FreeCAD / SolidWorks / Fusion360 | ❌ **不直接支持 `.CATPart`** |

⇒ **所以导出 STEP 很重要** —— 它几乎人人能开 ✓
