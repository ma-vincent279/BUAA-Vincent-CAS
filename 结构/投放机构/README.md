## 一、库里有什么

**12 个 CATIA 零件文件**（`.CATPart`，共约 4.2 MB），来自外置固态盘的 `模型/` 目录，
已按用途重新分类：

```

│   ├── chilun.catpart              齿轮
│   ├── chitiao(2)(1).CATPart       齿条
│   └── dianjijia3(1).CATPart       电机架 / 舵机架
├── 板件/
│   ├── fashejiashangbanboost.CATPart   发射架上板
│   └── daoxianghuangreatboost.CATPart  导向环
├── 图传/
│   └── funrucamerashelternew.CATPart   相机 / 图传外壳
└── 连接件/
    ├── fashejialianjie.CATPart         发射架连接件
    ├── ganzi10lianjie.CATPart          10 mm 管连接件
    ├── ganzi16lianjie.CATPart          16 mm 管连接件
    └── lianjienew1/2/3.CATPart         通用连接件（新版 1/2/3）
```

**【源码事实】** 这些命名与代码里的用法**互相印证**：
`k.py` 用 **AUX5 通道**（`PWM_AUX_FUNC5 = 411`，PWM **900~2100 µs**）
驱动投放机构：**1500 µs 锁定**、**2000 µs / 1000 µs 分别放第 1 / 第 2 瓶**（**两瓶方向相反**，与镜像挂载一致），
投放脉冲保持 **1.0 s**。

## 二、投放机构：它大概是怎么工作的【待验证】

结合**文件名**（齿轮 / 齿条 / 电机架）与**代码**（PWM 舵机通道），推断：

```
  舵机 / 电机  ──►  齿轮  ──►  齿条  ──►  直线运动（推出 / 拉回）
 (AUX5 PWM)      (chilun)   (chitiao)        ↓
                                      载荷脱钩 / 闸门打开
```

⇒ **齿轮齿条把旋转变成直线**，用直线行程完成"挡住 / 放开载荷" ✓

**为什么这么设计（【经验/建议】）**：
- 直线机构**行程可控、重复性好** —— 投放机构的动作一致性直接影响落点散布
- 齿轮齿条**不会像直接舵机臂那样受侧向外力影响**（载荷在飞行中会晃）

> **【待验证】以下都还没确认，需要实物或原作者补充**：
> - 到底是**舵机**还是**电机+电调**（代码只发了 PWM，两种都可能）
> - 行程多少 mm、齿轮齿数 / 模数、材料与工艺（打印 or CNC）
> - 锁定状态的保持力（能不能抗住飞行振动）
> - **装机方位**：释放口相对**相机光轴**的偏移（这个直接影响补偿标定，见下）

## 三、和"投不准"的关系（重点）

**【源码事实】** 载荷**不在机身重心上**，而且是**左右镜像挂载**：
第 1 瓶在机体**右侧**，第 2 瓶在**左侧**。

⇒ 三个后果：

| 后果 | 说明 |
|---|---|
| **1. 落点 ≠ 飞机正下方** | 释放口相对相机光轴有横向偏移 ⇒ 需要**按瓶补偿** |
| **2. 两瓶的补偿符号相反** | 镜像挂载 ⇒ 第 2 瓶的补偿必须反号（**早期这里错过，导致"第 2 投总偏左"**）|
| **3. 投放瞬间给飞机力矩** | 单侧卸掉载荷 ⇒ 飞机会被推一下 ⇒ 这是释放判据要考虑的因素之一 |

**【源码事实】** 当前实机版的投放补偿**已归零**（`K_ZERO_COMPENSATION = True`）——
因为 2026-10-12 换了相机画幅（`D25`，改 130° 原生画面）后，
**旧补偿是在旧相机模型下标定的，继续用会系统性偏掉**。
⇒ **等实机首飞用卷尺量出落点，再重新标定**（流程见 [`../复现指南.md`](../../技术文档/配置仿真环境.md) 与首飞清单）。

## 四、怎么打开这些文件

| 工具 | 能开吗 | 说明 |
|---|---|---|
| **CATIA**（原厂）| ✅ | 唯一能完整编辑的 |
| **eDrawings**（免费查看器）| ✅ 只读 | 免装 CATIA 就能看 |
| **3DEXPERIENCE / DraftSight** | 部分 | — |
| FreeCAD / SolidWorks / Fusion360 | ❌ | **不直接支持 `.CATPart`** |

**【经验/建议】** 如果你手上没有 CATIA：
1. 找**原作者**导出一份 **STEP（`.step`/`.stp`）** —— 这是通用中间格式，几乎所有 CAD 都能开
2. 或者用 **eDrawings** 至少能看和测量
3. 建议**把 STEP 也一起入库**（体积远小于 CATPart，且人人能开）—— **【待验证】目前仓库里还没有 STEP**

## 五、加工 / 打印建议【经验/建议】

- **投放机构受力件**（齿条、齿轮、电机架）：建议 **CNC 或高强度材料打印**（如 PA-CF / PETG），
  PLA 在长期振动 + 冲击下会蠕变
- **板件 / 连接件**：打印件即可，但**螺孔处要加厚**或埋铜螺母
- **相机外壳**：注意**遮光**（下视相机怕杂散光），并留出**散热孔**（机载电脑附近温度高）
- **【经验/建议】装配后必做的一件事**：把飞机摆平，用卷尺量出
  **"释放口在地面的投影"相对"相机光轴在地面的投影"的偏移**（两个方向都要量）——
  这个值就是补偿的**起点**，比纯靠实飞反推快得多

## 六、缺什么（给后来人的待办）

| 缺的东西 | 为什么需要 |
|---|---|
| **总装图 / `.CATProduct`** | 现在只有零件，没有装配关系 ⇒ 不知道零件之间怎么装 |
| **STEP 导出件** | 让没有 CATIA 的人也能看/改 |
| **二维加工图**（尺寸公差）| 替换零件时要用 |
| **实物照片**（装配好的机构）| 文档里最有用的东西，**强烈建议补** |
| **释放口相对相机光轴的实测偏移** | 补偿标定的起点（见第五节）|
| **机构的行程 / 保持力 / 循环寿命** | 判断可靠性 |

> 📌 **给后来人**：缺的这些**不难补**，但**拖一届就没人说得清了** ——
> 建议下一届拿到实物后**第一件事就是拍照 + 量尺寸 + 导出 STEP**。
