> ⚠️ **`.ulg` 飞控日志不在仓库里**（`.gitignore` 排除了，75 MB）—— 需要它们请从**外置固态盘**取。

**日志分两种，不要混**：

| 类型 | 谁产生 | 里面有什么 | 怎么读 |
|---|---|---|---|
| **节点日志** `*_mission_*.log` | 机载节点 stdout | 状态机流转、伺服明细、**释放行（含释放残差/触发方式）** | 直接看，或跑 `scripts/analyze_k_flight_20261013.py` |
| **飞控日志** `*.ulg` | PX4 自身 | 50 Hz 姿态/位置/速度/电机输出、EKF 内部量 | pyulog / PlotJuggler / ULogViewer |

**两者要配合看**：节点日志告诉你"**节点认为发生了什么**"，ULog 告诉你"**飞机实际做了什么**"。
很多结论只有对齐两者才能得出（例：`scripts/analyze_e_flight_20260923.py` 用 corr=0.90/0.95 证明了相机反投影是准的）。

## 三、几次关键飞行（值得单独看）

### 3.1 2026-09-23 `e`：**两发都没中 —— 但根因不是瞄错桶**

- **现象**：两次都是 `25.0s 兜底`（不是收敛即投），释放残差 9.2 / 10.3 cm
- **根因**（**【实测数据】** `scripts/analyze_e_flight_20260923.py`）：
  把节点日志的"等效地面误差"与 ULog 的"飞机 vs 自己设定点"跟踪误差逐点对齐 ⇒
  **corr = 0.90 / 0.95，中位比值 1.01 / 1.10**
  ⇒ **摄像头/反投影完全准确**（长期怀疑的"相机标定偏差"可排除），
  **误差 100% 来自"飞机没停在桶上方"**
- **关键结论**：门限是 `10px ≈ 3~4cm`，而实机误差 9~18 cm ⇒ **永远达不到** ⇒ 必然兜底

### 3.2 2026-09-24 `e`：**两发都中**（现场确认）

- 释放残差 **2.60 / 1.78 cm**，都是"收敛即投"（第 7.2 s / 3.5 s）
- 释放脉冲干净（2000 µs 保持 1.099 s / 1000 µs 保持 1.001 s）
- ⇒ 证明**判据在实机上可以满足**（这是 `k` 沿用同款判据的信心来源）

### 3.3 2026-09-27：**找到"第 2 投总偏左"的真根因**

- **【实测数据】** 两瓶是**镜像挂载**：第 1 瓶在机体**右侧**，第 2 瓶在**左侧**，
  而代码给两瓶用了**同一个横向补偿** ⇒ **第 2 瓶方向是反的** ✗
- 用 4 次实测落点反推所需补偿：第 1 瓶 +9.8~+12.8 cm，**第 2 瓶 −7.2~+2.3 cm（必须反号）**
- ⇒ **教训：机械不对称，补偿就必须分开标定。**

### 3.4 2026-09-30：**坠机（动力失效）**

- **【实测数据】** 飞行 113.4 s 时**电流 41.7 → 0.0 A，电压 22.92 → 23.50 V（开路）**，
  但飞控 PWM 正常满舵、5 V 轨正常、电池 `connected=1/faults=0`
  ⇒ **断点在电流采样点之后、电调之前** ⇒ 现场确认：**主供电线烧断**
- **前兆可测**：该趟**起飞峰值电流 72.1 A**（历史 40~57 A），
  且用与电池模型无关的 V-I 回归斜率看，**该趟是唯一"末段内阻不降"的**（18.47 mΩ，比历史高 ~5 mΩ）
- ⇒ **【经验/建议】起飞前必看：峰值电流 + 电池内阻趋势。**

### 3.5 2026-10-06 `f`：**自激振荡**

- **现象**：低空前 5~7 s 稳、之后越来越大，保持段设定点速度 0.07~0.27 m/s 不停，26 s 兜底释放
- **结构原因**：低空每帧重建瞄准点，而"桶估计 = 飞机位置 + f(像素, 高度, 姿态)"**含飞机自身姿态**
  ⇒ **姿态 → 瞄准点 → 飞机 → 姿态** 的低频正反馈
- **修法**：`i` 改成 **1.2 m 处只算一次偏移 + 冻结瞄准点 + 定点保持 + 必投** ⇒ **物理切断反馈**
- **【实测数据】** 修完后实机 12 趟全部 7~12 s 收敛

## 四、怎么分析一次飞行（标准流程）

```bash
# ① 拿到节点日志（k 版本: bash ~/fly/k.sh 会自动落盘到 ~/fly/log/）
# ② 跑分析器（回答"能不能满足 3cm/2.0s"）
python3 scripts/analyze_k_flight_20261013.py <日志> [--ulog <x.ulg>]

# ③ 想看飞控侧（悬停漂移 / vxy 静定占比）
python3 scripts/analyze_k_flight_20261013.py <日志> --ulog <x.ulg>

# ④ 历史版本的专用分析脚本（都在 scripts/ 下，真实存在）
ls scripts/analyze_*.py scripts/check_*.py
```

**几个常用的历史分析脚本**（这些是真实存在的文件）：

| 脚本 | 用途 |
|---|---|
| `analyze_k_flight_20261013.py` | **当前主线**：能否满足 3cm/2.0s |
| `analyze_e_flight_20260923.py` | 节点日志 vs ULog 双链路对齐（证明反投影准确）|
| `analyze_f_oscillation_20261008.py` | f 的振荡量化归因 |
| `analyze_dwell_consistency_20261007.py` | 4 趟 8 投的停留一致性（`dev` 指标）|
| `check_hold_accuracy_20260930.py` | 悬停精度 |
| `check_release_stability_20261006.py` | 释放瞬间稳定性（50 Hz ULog）|
| `analyze_hover_probe.py` | 仿真的悬停地板（这个仿真信不信得过）|

## 五、从实飞里学到的、已经写进代码的东西

| 教训 | 落到了哪里 |
|---|---|
| 飞机停不下来 ⇒ 判据要落在"实际能到的范围" | `k` 的容差 3 cm + 三级保底 |
| 相机反投影是准的，误差在"飞机站位" | 判据在**机体坐标系**算（对绝对漂移免疫）|
| 两瓶镜像 ⇒ 补偿必须分开 | 按瓶补偿常量（当前归零待标定）|
| 低空每帧重建瞄准点会自激 | 只算一次 + 冻结（`i` 起沿用）|
| 贴边框会被裁剪 ⇒ 中点偏 | 冻结样本排除贴边框 |
| 起步/刹车会晃 | `k` 的 `K_FWD_RAMPIN_M = 3.0` 起步斜坡 |
| 目标追踪器必须"已确认" | 冻结只认已确认追踪器 |
| 供电线会烧断 | 写进首飞检查清单 |

## 六、给后来人的建议【经验/建议】

1. **每次飞完当场记录**：日期 / 版本 / 天气风况 / 现场落点（**卷尺，两个带符号分量**）/
   落点是否弹跳 / 异常现象 —— 事后补记经常记不清
2. **节点日志和 ULog 一起收**，缺一个就可能归因不出来
3. **落点必须量两个分量**（沿航向 / 垂直航向），不要写"偏左下方"这种描述 ✗
4. **一次只改一个变量**：这个项目的历史版本（`a`~`j`）就是这么做的 ——
   每个版本只改一处，便于归因
5. **把当天的日志和结论写进** [`../project_log.md`](../project_log.md)，别只留在脑子里
