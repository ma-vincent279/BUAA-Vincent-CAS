# 2026 CUADC — 多旋翼无人机侦察与救援

2026 CUADC（中国大学生飞行器设计创新大赛）多旋翼无人机侦察与救援赛项的备赛记录。

完整记录这一轮备赛的技术路线：任务规则拆解、仿真环境搭建、伺服投弹算法的设计与验证、
实机首飞准备与飞行日志复盘。代码全版本、实飞数据、机械模型、飞控参数一并归档。

## 我们在做什么

无人机自主完成：**起飞 → 飞到投放区 → 找到 3 个白桶 → 选出分最高的两个 →
视觉伺服到桶正上方 → 从 1.2 m 投下两个载荷 → 侦察区 → 返航降落**。

其中**投弹**是最难的环节：不用"算好坐标盲投"，而是**全程闭环** ——
摄像头每帧给出"桶相对飞机"的偏移，把飞机挪到桶正上方，
**当这个偏移连续 2.0 秒小于 3 厘米时立刻投**。

## 快速上手

```bash
# ① 刚 clone 下来, 先恢复出可运行的工作空间
git clone --recurse-submodules git@github.com:ma-vincent279/BUAA-Vincent-CAS.git ~/SITL
cd ~/SITL && bash 恢复工作空间.sh

# ② 跑一轮仿真
colcon build --packages-select drone_drl
bash scripts/test_k.sh              # 默认 Gazebo Harmonic
bash scripts/cleanup_sim.sh         # ⚠ 每轮前必清进程

# 离线验收（秒级，不需要仿真）
python3 scripts/test_k_servo_20261011.py   # 仿真侧 104 项
python3 scripts/test_k_fly_20261013.py     # 实机侧 42 项
```

详细步骤见 [`技术文档/配置仿真环境.md`](技术文档/配置仿真环境.md) ✓

> **完全没接触过？** 建议先花 15 分钟读 [`技术全解.md`](技术全解.md)（一页看懂整个项目），
> 再按 [`从零开始的CUADC生活/说明.md`](从零开始的CUADC生活/说明.md) 的顺序往下走 ✓

· uXRCE-DDS · **Gazebo Harmonic** · YOLOv8 + TensorRT · 单目下视相机（无畸变，对角线 130°）
