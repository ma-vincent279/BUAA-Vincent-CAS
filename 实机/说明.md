# 实机 —— 机载侧

这里放**实机（Jetson 机载电脑）相关的一切**。

> 机载平台：**NVIDIA Jetson Orin NX** · Ubuntu 22.04 · ROS 2 Humble
> 环境搭建见 [`../技术文档/配置Jetson机载环境.md`](../技术文档/配置Jetson机载环境.md)

## 里面有什么

| 目录 | 内容 |
|---|---|
| **代码/** | 实机侧节点 |
| ├ 任务节点/ | 实机版任务节点（`k` 及全部历史版本）|
| └ 视觉节点/ | `see.py` —— YOLOv8 检测 → `/bucket/detections` |
| **脚本/** | 板载启动脚本（`k.sh` 自动落盘日志）|
| **备份/** | **164 个 `.bak`** |
| **工作空间/** | ★ **整套打包** —— 完整 `fly/` 工作空间（照搬环境里的命名）|

## ⚠️ 两条平行血统（很重要）

| | 仿真 | 实机 |
|---|---|---|
| 工作空间 | 顶层 `src/` | 顶层 `fly/` → 板载 `~/fly/` |
| 任务节点 | `drone_drl/k.py` | `fly/src/fly/fly/k.py` |
| 血统源 | `drone_drl/i.py` | `fly/src/fly/fly/i.py` |

⇒ 「实机 k 与仿真 k 的 diff」**没有意义**（差 154 行全是实机适配）。
**该保证的是**：①每版 vs **它自己的** `i.py`；②**两版之间 34 个 `K_*` 常量不许漂移** ✓

## 部署与首飞

```bash
python3 scripts/test_k_fly_20261013.py      # 上板前离线验收 42 项
bash scripts/deploy_k_jetson_20261008.sh    # 推代码 (自动备份 + 编译 + 校验 src==install)
bash ~/fly/k.sh                             # 首飞 (日志自动落盘)
python3 scripts/analyze_k_flight_20261013.py <日志> [--ulog <x.ulg>]
```

## 实机侧的环境常量（与仿真不同）

| 常量 | 实机 | 仿真 | 为什么不同 |
|---|---|---|---|
| `K_SIM_NO_BALLISTIC` | **False** | True | **实机有真实弹道** |
| `K_SIM_IDEAL_CAMERA` | **False** | True | 实机相机有噪声/延迟 |
| `K_TARGET_PLANE_H` | **−0.278** | 0.0 | 地面高度基准不同 |
| `K_ZERO_COMPENSATION` | True | True | 都归零，等实机标定 |
