## 二、★ 为什么降到最小 —— 而且这同时解决了"定高"

### 2.1 【源码事实】这个参数**同时管水平和高度**

```cpp
// src/modules/ekf2/EKF/aid_sources/gnss/gnss_height_control.cpp:53
float noise = math::max(gps_sample.vacc, 1.5f * _params.ekf2_gps_p_noise);
//                                    ↑ RTK 自报的垂直精度      ↑ 1.5 × EKF2_GPS_P_NOISE
//                                                      （取两者中较大的那个）
```

⇒ **GNSS 高度的观测噪声 = `max(vacc, 1.5 × EKF2_GPS_P_NOISE)`** ✓

**代入数值**：

| | `1.5 × P_NOISE` | 实际生效的噪声 |
|---|---|---|
| 改前（0.5）| **0.75 m** ✗ | **0.75**（因为它比 RTK 自报的 `vacc` 大 ✗）|
| **改后（0.01）** | **0.015 m** ✓ | **`vacc`** ← **让 RTK 自己说了算** ✓✓ |

⇒ **改后 = "按 RTK 自报的精度加权"** ✓✓ —— **这就是真正的"RTK 定高"** ✓

### 2.2 水平方向同理

`EKF2_GPS_P_NOISE` 的原文就是 *"Measurement noise for GNSS position"* ✓
⇒ 我们的 RTK 是 `eph = 0.000 m` ✗ 而参数说 0.5 m ✗
⇒ **卡尔曼增益被压小 10~25 倍** ⇒ 位置靠惯性递推 ⇒ **缓慢漂移** ✗
