# 项目报告 (2026-06-10 侦察任务)

### 项目目标

在 PX4 SITL Gazebo 仿真环境中，实现无人机飞往 **55m 外侦察区**，通过**下视摄像头 + PID 像素偏差视觉伺服**，依次对 **5 个白色圆筒**进行**视觉悬停侦察**的完整任务闭环。任务节点不依赖投放系统，独立启动。

### 系统架构

```
scout.world (Gazebo)
  └─ 5 个白色圆筒 (高15cm, 直径20cm), NED x≈(-1,1), y≈(52,57)

scout_detector  ──→  /scout/detection (ROI)
  │  5 筒坐标参数, /scout/target_id (Int32) 切换目标
  ↓
scout_mission  ──→  /fmu/in/trajectory_setpoint (速度/位置)
  │  8 状态机, PID 像素伺服, heading 持续更新
  │  不依赖 payload_dropper / drop_judge，独立启动
```

### 开发迭代过程

#### 迭代 1：初始创建

- 新建 `scout.world`（5 个白筒，Gazebo 54~58, -0.5~2.0）
- 新建 `scout_detector.py`（仿照 bucket_vision_detector，`/scout/detection` + `/scout/target_id`）
- 新建 `scout_mission.py`（8 状态机，PID 伺服，逐个悬停 2s）

#### 迭代 2：FORWARD 方向修复

- **Bug**：FORWARD 沿 heading 方向飞行（83°~94°），55m 后 NED x 偏移 ±7m，完全错过白筒
- **修复**：FORWARD 改为纯东方向 (NED y)，不依赖 heading；SEARCH 同改

#### 迭代 3：SEARCH 冲过头 + PID 振荡

- **Bug 1**：SEARCH 持续往东飞 0.5m/s，飞过侦察区越走越远
- **修复 1**：SEARCH 改为悬停 + y>60m 上限
- **Bug 2**：TRACK 像素误差正负交替 (±150px)，PID 剧烈振荡无法收敛
- **根因 2**：mission 的 heading 锁死在初始值，detector 用实时 heading，`_body_to_ned` 方向错误
- **修复 2**：`_cb_local` 持续更新 heading，同时降低 PID 增益 (KP: 0.004→0.0015, KD: 0.002→0.0005, MAX_VEL: 1.5→0.6)

#### 迭代 4：TRACK 秒过 + FORWARD 卡住

- **Bug 1**：`_stabilize_start` 未重置，后续筒复用上一筒的稳定时间，瞬间进入 HOVER
- **修复 1**：每次进入 TRACK 前 reset `_stabilize_start = None`
- **Bug 2**：`dist < 10.0` 条件吞掉 `dist < POS_ARRIVE_DIST`，FORWARD 永远进不了 SEARCH
- **修复 2**：嵌套 if 结构

#### 迭代 5：白筒不可见

- **Bug**：FORWARD 飞到 y=55 后 SEARCH 才开始，前面 y=52-53 的筒已被飞过；白筒 NED x 散布 ±2.5m 超过 FOV 半宽 2.46m
- **修复**：FORWARD 提前停 y=50；白筒 NED x 散布缩小至 ±1m；SEARCH 慢速前飞搜索

### 最终状态机流程

```
TAKEOFF(爬升至3.5m)
  → FORWARD(飞往 NED(0, 50) 纯东方向)
  → SEARCH(0.5m/s 前飞搜索) → TRACK(PID+高度锁定, err<40px 2s)
  → HOVER(2s, "侦察点 1 完成") → switch → SEARCH
  → ... (重复 5 次)
  → RESULT("侦察任务完成")
  → RETURN → LAND(disarm)
```
