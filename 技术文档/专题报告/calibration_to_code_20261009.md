## 2. ① `TARGET_PLANE_H` —— 两步

### 2.1 卷尺法（2 分钟，先拿符号）

| 步 | 做法 | 记 |
|---|---|---|
| a | 飞机放平整地面、正常起落架姿态、**卸桨** | |
| b | 量**下视相机光心（镜头前端）→ 地面** | `C_landed = ____ m` |
| c | 把**比赛用的那个桶**放同一水平地面，量**桶口沿 → 地面** | `h_rim = ____ m` |
| d | `TARGET_PLANE_H = C_landed − h_rim` | `= ____ m` |

**自检**：SITL 用 `C_landed=0.83`、`h_rim=0.375` ⇒ `0.455` ✓ 与仿真几何吻合（说明式子对）。
**预期**：实机大概率是**负值**（−0.05 ~ −0.20），与 SITL 相反。

### 2.2 视觉法（~15 分钟，**取这个当最终值**）

1. **先把飞机放正常落地位置启动 **`m`** 节点**（让 `home_z` 落在正确基准），**再抬到台面上**，`H ≈ 1.2~1.5m`（**与投放高度一致**）。
2. 水平尺确认 **pitch/roll < 1°**；桶从光轴正下方向**垂直航向**移开一个**已知** `ρ_true`（铅垂线 + 卷尺）。
3. 从日志 `TRK-DBG` 行取每个框的 `→NED(x,y)`（那就是 `_roi_to_ned` 的原始输出），配合同秒的飞机 NED 与 Home：

   $$est = \big|\,NED_{box} - (NED_{ac} - home)\,\big|\qquad h = H\left(\frac{\rho_{true}}{est} - 1\right)$$

4. **采 3~5 秒取中位数**（别用单帧），至少做 `ρ_true = 0.20 / 0.30 / 0.40 m` 三档：

   | 序 | H | ρ_true | est | MAD | 反解 h |
   |---|---|---|---|---|---|
   | 1 | | 0.20 | | | |
   | 2 | | 0.30 | | | |
   | 3 | | 0.40 | | | |

5. **判读**：
   - 三档 `h` 一致在 **±1cm** ⇒ 取中位数。
   - `h` 随 ρ 单调漂移 ⇒ 那是**可见侧壁**二阶项，取 **ρ ≈ 0.24m** 处的值（实测冻结离轴中位 23.6cm，那才是工作点）。
   - `MAD > 1cm` ⇒ 检测不稳，先解决检测。
   - 与卷尺法差 **> 5cm** ⇒ 还有别的系统项（相机 yaw/畸变/非比赛桶），**先别改代码**。

## 3. ②③ `Y` / `XF` —— 铅垂线静态法

1. 飞机不动、**水平**、**不解锁**；卸桨。
2. 把桶心放在**1 号投放口的铅垂线**正下方（用铅垂线从真实释放点垂下）。
3. 采 3~5 秒中位数，读 `est`（同样从 `TRK-DBG`）与飞机自身位置。
4. 记 `ρ_true` = 桶心相对**飞机原点**的机体 (前, 右) 分量；记 `est` = 同一次读数。
5. 解：
   $$
   Y_{B1} = \rho^{右}_{true} - est^{右}\qquad
   XF_{B1} = est^{前} - \rho^{前}_{true}
   $$
   （`Y>0` = 瞄准点左移；`XF>0` = 瞄准点朝起飞点方向后移 —— 与代码注释的语义一致）
6. 换到**2 号投放口**重复，得 `Y_B2 / XF_B2`。

> 这一套就是 CUADC 那份 `视觉标定/` 的核心（P1/P2 分别实测，不用镜像值）。**一次静态测量替代我们的飞行拟合。**

## 7. 常见错误（踩过的）

1. **把 `h` 折进 `XF`/`Y`** —— 一个可标定的硬件常数就变成了随场地漂移的经验数。
2. **用 SITL 的 0.455 填实机** —— 那是"桶浮在离地 0.375m + 相机在生成点 0.83m"的仿真几何。
3. **标定时飞机不水平** —— 姿态项 `H·tan(pitch)` 会污染读数（它是加性的、随姿态变；`h` 是乘性的、不随姿态变）。
4. **改完只改一边** —— `m` 改了 `l` 没改 ⇒ 验证结论不成立。**改完必须跑搬运检查器**。
5. **拆装后不重标** —— 动过相机/机架/投放机构/换桶 ⇒ `C_landed` 或 `h_rim` 变了。
6. **忘了 `colcon build`** —— `install/` 是普通拷贝不是 symlink；板上还要防"install 副本被清成 0 字节"（起飞前 30 秒 `sha256sum` 自查）。

## 附: 哪些常量**不该**照搬到 SITL (2026-10-09 追加 30)

标定出来的 7 个常量里, **3 个是由环境和仿真器决定的**, 不是由实机决定的:

| 常量 | 实机 (fly) | SITL | SITL 值的来源 |
|---|---|---|---|
| `TARGET_PLANE_H` | **−0.278** | **0.0** | `yolov8_bucket_detector._gt_ground_circles()` 把桶当"**参考平面上的圆**"投影 (`dz = -drone_z`, 不含桶高) ⇒ 与 `_roi_to_ned` 的平面求交**互为逆运算** |
| `HFOV` / `VFOV` | **89.8° / 58.5°** | **85° / 54°** | 同一检测器 `yolov8_bucket_detector.py:261-264` **硬编码**并用 `self.fx/self.fy` 生成像素 ⇒ 节点必须同参 |

而 `Y_B1 / Y_B2 / XF` **两侧相同** (机身确实一样)。

**写错的后果 (实测)**: 默认 `project_mode=ground` 下节点深度从 `H` 变 `H−0.278` (H=1.2 时低估 **23%**), 再叠加 `349.22/321.12 = 1.0875` 的尺度误差 ⇒ SITL 几何误差 **82 mm**, 会被误读成"标定坏了"。

**改 SITL 侧环境常量**: `python3 scripts/patch_sitl_env_20261009.py` (只碰 SITL 两份, 有安全闸)。
**机器把关**: `python3 scripts/check_drop_portability_20261009.py k l` 的 **A2 节** —— 用检测器真实投影 + 节点真实反投影做往返, 三条判据: 平面精确 `0.0` / 内参与检测器**逐位相等** / 往返误差 ≤ **1 px** 量化地板 (当前 0.4375 px)。

**改完不用重新部署**: fly 两份一位不动 ⇒ 板载 sha 不变。
