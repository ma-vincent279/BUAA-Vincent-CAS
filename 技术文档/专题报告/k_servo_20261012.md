## 4. 负面结论：**pred 速度外推在振荡机体上无效**

同一场景四版释放判据实测（第一投落点）：

| 判据 | 第一投 | 第二投 |
|---|---|---|
| `残差 ≤ 容差 ∧ vxy ≤ 0.15`（**现默认**）| **8.0 / 8.2 / 8.4cm** | 4.5 / 0.7 / 15.9cm |
| `pred ∧ 残差 ≤ 2×容差` | 12.6cm | 22.0cm |
| `pred` 单独 | 18.5cm | 17.2cm |

**最刺眼的一条**：第 235331 轮第二投 `残差=1.9cm` 而 **`pred=14.1cm`**，实际落点 **0.7cm** —— pred 误差 13.4cm，残差误差 1.2cm。

**机理**：pred 假设释放后 0.5s 内速度不变，而本机悬停是 **~1s 周期极限环**（±0.1~0.25m/s）⇒ 半个周期后速度反向，预测当场失效。
**处置**：`K_USE_PRED_RELEASE = False`（默认关），pred 仍计算并逐秒记录，作为"能否速度外推"的证据留档。

**另一条实测规律**：`落点 ≈ 残差 + 0~6cm`（6.4→8.4 / 1.9→0.7 / 8.4→9.8 / 15.5→22.0 / 2.3→3.5 / 3.2→3.1）⇒ **残差才是可用的落点预测器**。

## 5. 剩余差距与下一轮候选

**差距**：15cm 桶需要落点 ≤7.5cm，实测中位 11.3cm ⇒ 差 ~4cm；而按 `落点 ≈ 残差+2cm` 反推，需要释放时残差 ≤5.5cm，实测中位 ~8-10cm。

**根因（已定位，属仿真/飞控层）**：SITL 悬停位置环在 1.2m 高度有 ±0.10~0.25m 的位置极限环与 ±0.25m/s 的速度波动。判据要求 `残差 ≤ 容差 ∧ vxy ≤ 0.15` —— 而极限环上"残差最小"与"速度最小"发生在**不同相位**，两者同时成立的时间窗很窄。

**下一轮候选（按性价比）**：
1. **判据只认"相位对齐的折返点"**：现在 0.15s 确认已在做；可进一步要求 `vxy` 单调下降（二阶判据）以确认是真折返而非穿越；
2. **进近末端降振**：TRACK 到位判据现在是 `dist<0.5 持续 3s`，可加"`vxy` 衰减到阈值以下"再进 REFINE（属中间控制，需用户同意）；
3. **D14 积分加低通（τ≈2s）**：现在 KI=0.3 直接吃振荡的残差矢量，可能在 ~1Hz 上给设定点注入激励；
4. **换判据坐标系**：把"残差 ∧ 速度"换成"残差 ∧ **残差变化率**"（在折返点两者同时最优）。

## 7. 第二轮补充（2026-10-12，D20/D21 + 两条决定性证据）

### 7.1 证据 A：**SITL 的载荷没有弹道** ⇒ 仿真里速度门与 pred 都是错的（D20）

逐投核对 30 个样本的 `|落点 − 桶估计|` 与日志 `残差`：

```
|落点 − 桶估计| − 残差 : 中位 +2.05cm   (范围 −3.5 ~ +19.2cm, 绝大多数 ≤4cm)
```

⇒ 仿真里「落点」**就是释放瞬间的飞机站位**（裁判读 `/drop/impact_rel` = 飞机坐标，载荷是虚拟的）。因此：

- **速度门 `vxy ≤ 0.15` 在仿真里是错的**：悬停极限环上飞机「穿越目标点」时速度**最大**、而那一刻残差最小 ⇒ 要求「残差小 且 速度小」几何上不可能 ⇒ **判据结构性不可满足**（这解释了 17 轮里绝大多数只能走必投兜底）。
- **`pred = |err − v·t_fall|` 在仿真里也是错的**：它会在飞机**偏开 v·t_fall（5~13cm）**时放行，而 SITL 正是按那个偏开位置算分。实测 `pred=1.6cm → 落点 12.6cm`（偏差 11cm ≈ v·t = 0.25×0.495 = 12.4cm）。

**处置**：`K_SIM_NO_BALLISTIC = True`（D20）—— 仿真判据**只认残差**，稳定性由「0.15s 确认 + 12s 必投」保证；**实机必须置 False**（载荷带着释放瞬间速度飞 0.495s，那时才需要速度项）。这与项目既有的「环境常量分侧」约定一致（`TARGET_PLANE_H` / `HFOV` 同款）。

### 7.2 证据 B：**飞控自报速度与位置不自洽**（D21 观测字段抓到的）

给新 k 补上 `FC()/EKF()` 观测字段后（D21，复用 `patch_ekf_tlm_20261009.py` 的锚点与文本），第 17 轮第一投 DROP 段：

```
飞机 NED x : 2.31 2.31 2.31 2.32 2.31 2.30 2.29 2.28 2.27 2.26      (12s 漂 5cm ⇒ 约 0.4cm/s)
同刻 vNED x: -0.08 -0.09 -0.10 -0.13 -0.15 -0.16 -0.17 -0.19 -0.22 -0.23   (自报 0.23 m/s)
FC(a2 n14 fs0 d0)  ← 全程 armed + OFFBOARD + 无 failsafe
```

**相差 ~55 倍，刚体上物理不可能。** ⇒ 仿真里 `vNED` 这个量**不可信**：既不能用来做速度门，也不能用来做 `pred`。同一趟飞机始终停在距设定点 **15cm** 处 12 秒不收敛（`EKF(1111 dr0 rst3/2/3/1 dbt=--)`：xy/z/vxy/vz 全有效、无 dead-reckoning、无对地测距）。

## 8. 第三轮补充（2026-10-12）：**撤回一条结论** + 两条新证据

### 8.1 ⚠ **撤回 §7.2 的"位置/速度不自洽（55×）"结论**

§7.2 我根据"12 秒里飞机只动 5cm、而 `vNED` 始终 −0.23 m/s"判定"速度与位置不自洽"。**这个判断是错的，属于我自己的分析错误**：

- 该机悬停在 **~1s 周期的极限环**上，**瞬时速度 0.2 m/s 而 1 秒净位移≈0 是必然的**（振荡相互抵消）；
- 用 1Hz 采样做位置差分去核对瞬时速度，方法本身就不成立。

**全量核对（18 轮，用各自日志的 1Hz 行做 `|自报v| / |Δpos/Δt|`）**：

| | 中位比值 | 总分 |
|---|---|---|
| 800 分那轮（002000） | **3.3** | 800 |
| 100 分那轮（004653） | **12.3** | 100 |
| 全部 18 轮 | 3.1 ~ 20.0 | 100×11 / 350×6 / 800×1 |

**比值与成绩无相关性**（800 分那轮的比值和 100 分那轮同档）⇒ 该指标不是判据。**撤回。**

**仍然成立的两条**（不受此影响）：
- 极限环上"残差最小"与"速度最小"发生在**不同相位** ⇒ `resid ≤ tol ∧ vxy ≤ 0.15` 这类合取判据在振荡机体上**结构性难满足**（这解释了大量兜底）；
- `pred` 依赖释放瞬间速度外推 0.5s，在 ~1s 周期上被半个周期后的反向抵消 ⇒ 仿真里（无弹道）系统性误导（§7.1）。

### 8.2 证据 C：真正的杀手是**稳态偏移**，不是时间不够（D22 判决性实验）

第 17 轮（004653）第一投：飞机 **12 秒**始终停在距设定点 **14~18cm** 处，而设定点在全程移动（积分项把命令点从 2.18 推到 2.08，飞机反向漂 2.27→2.31）。

**判决性实验 D22**：把必投兜底从 12s **临时拉到 25s**（run 010326）。结果：

```
DROP #1: 残差=8.1cm  更新=36 新帧  触发方式=机体残差8.1cm<=8cm 保持0.15s
```
两投都在 **~3.6s** 由残差判据**自己**释放（`更新=36` = 36 个新帧 ≈ 3.6s），**25s 的兜底窗口根本没被用到** ⇒ **"残差地板"不是时间问题**。已按最小改动原则**回退到 12.0s**。

**该干净轮的落点**：15cm 桶 **7.8cm**（半径 7.5cm，**只差 0.3cm**）/ 20cm 桶 **8.0cm** ⇒ A 区 300 分，总分 **350/800**。

### 8.3 证据 D：**并发实例污染裁判**（已加守卫）

### 9.4 结论（第四轮）

- **控制逻辑、判据实现、离线一致性全部已验证**（74/74；含 EKF 偏置免疫 Δ=0.000mm、积分收敛与限幅、几何往返 ≤0、桶径反推 ≤0、通用常量定义检查）。
- **"落点不准"的根因是仿真环境本身**：投放区的位置保持地板 **RMS 31cm / 回环半径 ~20cm / 速度 0.25 m/s**，而小桶需要 ≤7.5cm。**这是任何判据改动都无法突破的上限**（已在 D22 用 25s 实验排除"时间"，用四版判据排除"判据"，用 74/74 排除"代码"）。

- **对照**：同一套 `k` 代码在**实机**上的历史到位精度是 **0.6~6.4cm**（`i` 的实飞记录），即实机位置保持比本 SITL 的投放区好 **5~50 倍** ⇒ **仿真在这里低估了系统能力**，不能用来判"能不能复现他们的精度"。

### 9.5 下一步候选（若继续）

1. **先修仿真地板再谈精度**：查投放区回环的成因（PX4 位置环增益 / EKF 在远端的估计质量 / 世界物理），把它压到 <5cm 再复测落点 —— 否则任何投放判据的收益都被 31cm 的地板淹没；

3. **换判据坐标系**（`残差 ∧ 残差变化率`）在回环上同样有效，但优先级低于 1。
