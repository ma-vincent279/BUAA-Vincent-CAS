## 四、相机

| 项 | 值 | 依据 |
|---|---|---|
| 类型 | USB 单目摄像头（`/dev/video0`），最高 1920×1080@30 fps | 【源码事实】`fly/CLAUDE.md` |
| 安装 | **固定下视**，光轴朝正下方（机体坐标系 −z）| 【源码事实】源码注释 |
| 视场 | **无畸变**，画面 16:9，**对角线 130°** | 【源码事实】`D25` |
| 等效焦距 | `FX = FY = 171.21 px`（按 640×360 计算）| 【源码事实】`FX=(√(640²+360²)/2)/tan(65°)` |
| 水平 / 垂直视场 | **123.70° / 92.87°** | 【源码事实】由上式反解 |
| 处理分辨率 | 640×360（1920×1080 全帧**缩放**，**不裁剪**）| 【源码事实】`see.py` |

> 【经验/建议】**广角是双刃剑**：130° 能一次看全 5 m 的投放区（3 m 高度覆盖 6.31 m），
> 但代价是桶很小 —— 5 m 处 15 cm 桶只有 **5.1 px**（旧 85° 视野是 10.5 px）。
> 我们为此把巡航高度从 5 m 降到 3 m，并放宽了残框过滤下限（`D28`、`D29`）。

## 五、投放机构

| 项 | 值 | 依据 |
|---|---|---|
| 舵机通道 | **AUX5** | 【源码事实】`PWM_AUX_FUNC5 = 411` |
| PWM 范围 | **900 ~ 2100 µs** | 【源码事实】`PWM_AUX_MIN5 = 900` / `PWM_AUX_MAX5 = 2100` |
| **锁定** | **1500 µs**（`AUX5_LOCK = 0.0` ⇒ `1500 + 0×600`）| 【源码事实】|
| **投放（第 1 瓶 / 第 2 瓶）** | **2000 µs / 1000 µs** —— **两瓶方向相反**！<br>（`AUX5_DROP = +0.83333` ⇒ 2000 µs；`AUX5_DROP2 = −0.83333` ⇒ 1000 µs）| 【源码事实】|
| **保持时长** | 投放脉冲保持 **1.0 s**（`AUX5_DROP_HOLD = 1.0`），之后回 1500 µs 锁定 | 【源码事实】|
| 控制方式 | `ManualControlSetpoint` → `/fmu/in/manual_control_input`，**200 Hz** | 【源码事实】需要超过 SBUS 接收机更新率（~111 Hz）才能覆盖 |
| 机械 | **齿轮 + 齿条 + 电机架**（CATIA 模型已入库）| 【源码事实】[`../结构/建模文件/投放机构/`](../结构/建模文件/投放机构/) |

**载荷**：两瓶（左右各一），**投放在机身两侧、不在重心** ⇒
投放瞬间会给飞机一个力矩 ⇒ 需要**两瓶分别补偿**（见下方"补偿"）。

> **【经验/建议】两瓶是镜像挂载**：第 1 瓶（先投）在机体**右侧**，第 2 瓶在**左侧**。
> 早期代码给两瓶用了**同一个横向补偿**，导致"第 2 投总偏左" ⇒
> **第 2 瓶的符号必须反过来**。详见 [`../留给后人的话/`](../留给后人的话/README.md)。

## 六、通信链路

```
        ┌──────────────┐   串口 DDS 921600 baud   ┌─────────────┐
        │ Jetson Orin  │ ◄══════════════════════► │  PX4 飞控    │
        │ (ROS 2 节点) │   /dev/ttyTHS1           │ (v1.17.0)   │
        └──────┬───────┘                          └──────┬──────┘
               │ USB                                     │ SBUS/PWM
        ┌──────┴───────┐                          ┌──────┴──────┐
        │ USB 相机      │                          │ 电机/电调    │
        │ 1920×1080    │                          │ + AUX5 舵机  │
        └──────────────┘                          └─────────────┘

        地面站 (QGC) ◄── 数传电台 57600 baud ──► PX4
```

| 链路 | 配置 | 依据 |
|---|---|---|
| **机载 ↔ 飞控** | 串口 DDS，**921600 baud** | 【源码事实】`SER_TEL2_BAUD = 921600`（与启动命令 `MicroXRCEAgent serial --dev /dev/ttyTHS1 -b 921600` 一致）|
| 飞控 ↔ 地面站 | 数传电台，57600 baud | 【源码事实】`SER_TEL1_BAUD = 57600` |
| MAVLink 实例 | `MAV_0_CONFIG = 101`，`MAV_0_MODE = 0`（normal），`MAV_0_RATE = 1200` | 参数 |
| GPS 端口 | `GPS_1_CONFIG = 201` | 参数 |

> **【经验/建议】** 机载节点必须在 **PX4 之前或同时**启动：它需要**持续发布** setpoint（>2 Hz），
> PX4 才允许切 OFFBOARD；晚启动会触发 offboard failsafe → AUTO_LAND。

## 七、定位（GPS / RTK）

库里有**两套**参数文件，对应两种定位配置：

| 文件 | 行数 | 用途 |
|---|---|---|
| [`PX4参数_GPS.params`](PX4参数_GPS.params) | 1055 | 普通 GPS |
| [`PX4参数_RTK.params`](PX4参数_RTK.params) | 1199 | **RTK**（多 144 项，主要是 RTK/串口相关）|

> 【经验/建议】**RTK 对"绝对位置"的帮助大，但对我们的投弹精度帮助有限** ——
> 因为我们的闭环是**相机直接看桶**（相对几何），不依赖绝对坐标。
> 详见 [`../技术全解.md`](../技术全解.md) 第三节。

## 八、装机检查清单【经验/建议】

### 上电前
- [ ] 桨装好、螺丝紧固
- [ ] 两瓶载荷装到位，**手动试一次**投放机构（确认 2000 µs 能真的放下）
- [ ] AUX5 舵机行程确认：**1500 µs = 锁定 / 2000 µs = 第 1 瓶投放 / 1000 µs = 第 2 瓶投放**（两瓶方向相反！）
- [ ] 相机镜头擦净、**朝正下方**、USB 插紧
- [ ] 电池电压正常、**供电线无破损**（有烧断先例）
- [ ] 机载电脑开机、ROS 2 环境能 `source`

### 起飞前（QGC）
- [ ] **QNH / `EKF2_HGT_REF` 与当地一致**（有高度基准偏 344 m 的先例）
- [ ] 罗盘无 `Strong magnetic interference`
- [ ] GPS/RTK 定位正常、`EKF` 无红字
- [ ] 数传链路正常
- [ ] 起降区净空、桨区无人
