## 一、接线与识别

### 1.1 物理连接

USB 线接飞控的 **USB 口**（`PX4 FMU v6C` 上就是那个 Type-C ✓）→ 插到电脑 ✓

### 1.2 确认认到了

```bash
ls /dev/serial/by-id/
#   期望: usb-Auterion_PX4_FMU_v6C.x_0-if00   ✓

lsusb | grep -i fmu
#   期望: 3185:0038 Auterion PX4 FMU v6C.x     ✓
```

> 我们这块板的 ID 是 **`3185:0038`** ✓

### 1.3 工具会自动找端口 ✓

**不用手动指定** ✓ —— `fc_param.py` 的 `find_port()`：

1. 先扫 `/dev/serial/by-id/`，挑名字里含 **`PX4` / `CUAV` / `FMU` / `PIXHAWK`** 的 ✓
2. 找不到就退回 `/dev/ttyACM0` / `ttyACM1` / `ttyUSB0` ✓

要手动指定：`python3 scripts/fc_param.py info --port /dev/ttyACM1` ✓

### 1.4 权限（Linux）

```bash
ls -l /dev/ttyACM0
#   crw-rw---- 1 root dialout ...    ← 需要在 dialout 组
groups | grep dialout || sudo usermod -aG dialout $USER   # 加完要重新登录
```

## 三、写参数（**RAM vs flash，这是关键** ✗）

PX4 的参数是**两级**的：

| 级别 | 命令 | 特点 |
|---|---|---|
| **RAM** | `set` | **立刻生效** ✓ **重启就还原** ✓ ← **先试就用这个** ✓ |
| **flash** | `save` | **持久化** ✓ 重启后仍在 ✓ ← **确认满意后再落盘** ✓ |

```bash
# ★ 先只改 RAM（零风险, 重启即还原）
python3 scripts/fc_param.py set EKF2_GPS_P_NOISE 0.02

# 试完满意 ⇒ 落盘
python3 scripts/fc_param.py save
#   或一步到位
python3 scripts/fc_param.py set EKF2_GPS_P_NOISE 0.02 --save

# 回退（改成原值再落盘）
python3 scripts/fc_param.py set EKF2_GPS_P_NOISE 0.5 && python3 scripts/fc_param.py save
```

### 3.1 落盘成功的标志

**开机日志**里会看到 ✓：

```
INFO [param] importing from '/fs/mtd_params'
INFO [parameters] BSON document size 3916 bytes, decoded 3916 bytes (INT32:86, FLOAT:100)
```

⇒ `INT32:86, FLOAT:100` = **186 个非默认参数** ✓
（PX4 **只存非默认的** ✓ —— 所以数字不大是正常的 ✓）

### 3.2 ⚠️ 改完之后要**重启**飞控

估计器（EKF2）类的参数在**初始化时读取** ✓
⇒ 改完 `EKF2_*` 要**断电重上**（或 `nsh "reboot"` ✓）才真正生效 ✓

## 四、参数怎么理解（读参数文件的格式）

从 QGC 导出的 `.params` 是 **tab 分隔**的：

```
sysid→compid→参数名→值→类型
1→1→BAT1_N_CELLS→6→6
```

| 字段 | 含义 |
|---|---|
| `sysid` | 系统 ID（我们永远是 1 ✓）|
| **`compid`** | **组件 ID** ★ 见下 |
| `参数名` / `值` / `类型` | （类型 6=INT32, 9=REAL32 ✓）|

### ★ `compid` 很重要

**一个 `.params` 文件里可能有多个组件的参数** ✗
例：我们的 `RTK_NEW.params` 里

| compid | 项数 | 是什么 |
|---|---|---|
| **`1`** | **1160** | ★ **飞控本体（PX4 参数）** ← **只有这些是我们要的** |
| `125` | 31 | 另一个 MAVLink 组件（**CAN 上的 RTK 模块自己** ✓，用的是 ArduPilot 风格命名 ✗）|

⇒ **回灌到 PX4 时，非 comp1 的项会被忽略** ✓（无害但是噪音 ✓）
⇒ 提取纯飞控参数：

```bash
grep -v '^#' RTK_NEW.params | awk -F'\t' '$2=="1"' | sort -t$'\t' -k3 > 干净版.params
```

### 用命令行读 `.params`（比手翻 1191 行快 ✓）

```bash
# 查一个参数
awk -F'\t' '$3=="BAT1_N_CELLS"{print $4}' 某份.params

# 列出所有 EKF2 参数
awk -F'\t' '$3 ~ /^EKF2_/ {print $3, $4}' 某份.params
```

## 五、⚠️ 三条**必须知道**的坑（都实测踩过）

### 坑 1 · **孤儿 NSH shell 会把飞控"假死"** ✗✗

PX4 只在收到 **`flags=0`（不要求响应）的 SERIAL_CONTROL** 时才关闭 shell ✓

⇒ shell 会话被 **`kill` / `timeout` 掉**，就会在飞控侧留下**孤儿会话** ✗
⇒ 症状：**USB 还在、但 0 字节、连写都阻塞** ✗
⇒ **软件无法自救**（写方向也堵了 ✗）⇒ **只能拔插 USB / 重新上电** ✗

| 该做 | 不该做 |
|---|---|
| 用 **`nsh "单条命令"`** ✓（它 try/finally + atexit + 信号处理，**保证发 close** ✓）| 用 `shell` 交互式 ✗ |
| 交互时用 **Ctrl-D** 退出 ✓ | 对 shell 套 `timeout` ✗ / `kill` 它 ✗ |

### 坑 2 · **`param select` 不带参数 ⇒ 空指针硬故障 ⇒ 飞控复位** ✗

⇒ **别敲裸的 `param select`** ✗

### 坑 3 · **PX4 的 `PARAM_VALUE.param_value` 是 float 字段** ✗

⇒ INT32 参数必须做「**float 位重解释成 int32**」✓
⇒ 不做的话 `EKF2_HGT_REF=1` 会读成 **`1.4e-45`** ✗
（工具里已修 ✓，但你自己写脚本时要记得 ✓）

## 六、其它安全规矩

| 规矩 | 说明 |
|---|---|
| **armed 状态下不改参数** ✗ | 工具本身会拒绝写 ✓（**飞行中改参数是事故来源** ✗）|
| **`set` 立刻进 RAM 并有反悔窗口** | ✓ 但 `save` 之后就没有了 ⇒ **改前先 `dump` 备份** ✓ |
| **一次只改一个变量** ✓ | 便于归因（我们的项目规矩 ✓）|
| **不要整机回灌画像** ✗ | 参数之间有耦合（机型→混控器→电机映射→电调协议）⇒ 会**把对的东西改错** ✗ |
| **`CAL_*` 绝对不能抄** ✗ | 那是"该机最后一次的传感器标定值" ⇒ 换机必须**重新标定** ✓ |
| **板级默认不要抄** ✗ | 不同型号飞控（`PX4_FMU_V6C` vs `CUAV_7_NANO`）的 board defaults 本来就不同 ✓ |
| **改完要重启**（EKF 类）✓ | 估计器参数在初始化时读 ✓ |

```bash
# EKF 健康（两个实例、姿态/位置是否收敛）

#   ekf2: available instances: 2
#   INFO [ekf2] 0: ... healthy, test ratio: 1.0000000 (0.00000) *
#   ekf2:0 EKF dt: 0.0089s, attitude: 1, local position: 0, global position: 0
#     ↑ local position 0 = 还没定位（室内无星正常 ✓, 户外有星应为 1 ✓）
```

**常见警告（都正常 ✓）**：

| 警告 | 含义 |
|---|---|
| `SPI_I2C] ist8310: no instance started` | 内置磁罗盘没接（`EKF2_MAG_TYPE=5` 只用外置做初始化 ✓）|
| `uavcan] GNSS Fix2 msg detected ... disabling Fix msg` | RTK 挂在 **CAN** 上 ✓ |
| **`Preflight: GPS fix too low`** | **室内无星** ✓ —— 但**这条会让飞机无法解锁** ✗ ⇒ 到户外见星即消失 ✓ |

## 八、飞控参数当"真值"用（读实飞日志里的参数）

`.ulg` 里可以读**飞行时**的部分参数 ✓：

```python
from pyulog import ULog
u = ULog('某趟.ulg')
for ds in u._data_list:
    if ds.name in ('sensor_gps','estimator_aid_src_gnss_hgt','estimator_status'):
        print(ds.name, list(ds.data.keys()))
```

**对本项目最有用的几个**：

| 话题 | 看什么 |
|---|---|
| `sensor_gps` | `eph`（水平精度）/ `epv`（垂直精度）/ `s_variance_m_s`（速度精度）⇒ **RTK 自报的精度** ✓ |
| `estimator_aid_src_gnss_hgt` | `observation_variance` / `fused` ⇒ **高度融合用的是什么噪声** ✓ |
| `estimator_aid_src_gnss_yaw` | 同上（双天线航向）✓ |
| `estimator_status` | **`pos_horiz_accuracy`** / `pos_vert_accuracy` ⇒ **精度判据** ✓ |

## 九、出事了怎么办

| 症状 | 处置 |
|---|---|
| `找不到飞控` | 检查 USB 线 / `lsusb` / dialout 组 ✓ |
| **USB 还在但 0 字节、写阻塞** ✗ | **孤儿 NSH shell** ⇒ **拔插 USB / 断电重上**（软件救不了 ✗）|
| `param select` 之后飞控复位 ✗ | 已知坑 ✓ 别再敲 ✓ |
| 参数读成 `1.4e-45` ✗ | INT32 位重解释没做 ✓ |
| 参数没生效 | ① 是否只改了 RAM（要 `save` ✓）② 是否重启（EKF 类要 ✓）|
| 想回到某个已知状态 | `python3 scripts/fc_param.py restore <备份> --yes` ✓（默认只演练 ✓）|
