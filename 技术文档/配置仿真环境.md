## 一、装依赖

### 1.1 系统与 ROS 2

```bash
# Ubuntu 22.04 + ROS 2 Humble (略去源的配置, 见 ROS 官方文档)
sudo apt update && sudo apt install -y ros-humble-desktop
```

### 1.2 ⚠️ Gazebo 与 ROS 桥接（**这一条最容易装错**）

```bash
# ✅ 正确的
sudo apt install -y ros-humble-ros-gzharmonic

# ❌ 不要装这个 —— 它默认是 Fortress 变体, 与 Harmonic 不兼容
# sudo apt install ros-humble-ros-gz
```

**【源码事实】为什么**：`ros-humble-ros-gz` 默认链接 `libignition-transport11`，
而 **Gazebo Harmonic 用 `gz-transport13` / `gz-msgs10`** ⇒ **桥不通** ✗

**验证**：

```bash
gz sim --versions          # 期望看到 8.x.x (Harmonic)
```

### 1.3 PX4-Autopilot

```bash
git clone --recursive https://github.com/PX4/PX4-Autopilot.git ~/PX4-Autopilot
cd ~/PX4-Autopilot
make px4_sitl_default
```

> 【源码事实】我们用 **PX4 v1.17.0**。

### 1.4 ⚠️ PX4 侧必须改的 4 行（**可回退**）

**【源码事实】** 为了让**外部环境变量能覆盖**模型/世界路径：

```bash
# 文件: ~/PX4-Autopilot/src/modules/simulation/gz_bridge/gz_env.sh.in
#
# 把:  export PX4_GZ_MODELS=<固定路径>
# 改成: export PX4_GZ_MODELS="${PX4_GZ_MODELS:-<固定路径>}"
# (PX4_GZ_WORLDS / PX4_GZ_PLUGINS / GZ_SIM_SERVER_CONFIG_PATH 同理)

cd ~/PX4-Autopilot
touch src/modules/simulation/gz_bridge/gz_env.sh.in
make px4_sitl_default
```

**不设环境变量时行为完全一致** ⇒ 安全 ✓

**回退**：

```bash
cd ~/PX4-Autopilot && git checkout -- src/modules/simulation/gz_bridge/gz_env.sh.in
make px4_sitl_default
```

## 五、⚠️ 每轮之前必须做的事

```bash
bash scripts/cleanup_sim.sh
```

**【实测数据】不清会怎样**：
- 残留 `gz sim` ⇒ 下一轮 `Task already running` + `gz_bridge failed to start`
  ⇒ **飞机根本起不来、0 投、挂到超时** ✗
- 残留 `ros_gz_bridge` ⇒ 一直往 DDS 灌 250 Hz 位姿数据，把 OFFBOARD 流**饿死**
  ⇒ 表现为**解锁要 24 s、飞机飞到 39 m 高** ✗

⇒ `test_k.sh` 自己也会清，但**手动再清一次更保险** ✓

## 七、三条硬规则（违反就飞不起来）

**【源码事实】** PX4 通过 `make px4_sitl` → `px4-rc.gzsim` → 读 `gz_env.sh` 拉起 gz。
有三条**踩过才知道**的规则：

| 规则 | 违反的后果 |
|---|---|
| ① **世界文件里绝对不能声明 gz 的 system plugin** | 与 `GZ_SIM_SERVER_CONFIG_PATH` 指向的 `server.config` **重复加载** ⇒ `Found 0 compass` / `barometer 0 missing` ⇒ **飞不了** ✗ |
| ② **世界文件必须有 `<spherical_coordinates>`** | GPS / 磁罗盘算不出来 ⇒ `Preflight Fail: Strong magnetic interference` ✗ |
| ③ **世界文件名（不含扩展名）必须等于 `PX4_GZ_WORLD`** | `Timed out waiting for Gazebo world` ✗ |

> **为什么是 ①**：gz 的 system plugin（物理、IMU、气压计、磁罗盘、navsat、相机…）
> 由 **`server.config` 全局加载**，**不是**由世界文件加载的。
> 世界文件里再写一遍 = 加载两次 ⇒ 传感器冲突 ✓
