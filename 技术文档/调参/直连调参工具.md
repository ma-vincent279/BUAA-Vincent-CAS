# 直连调参工具（不用 QGC）

> 工具：`SITL/脚本/fc_param.py` —— 通过 **USB / MAVLink** 直接读写飞控参数。
>
> 用途：**现场没有 QGC、或者要批量比对参数**的时候 ✓

---

## 一、它能做什么

| 功能 | 命令 |
|---|---|
| 读取全部参数 | `python3 SITL/脚本/fc_param.py dump` |
| 读单个参数 | `python3 SITL/脚本/fc_param.py get EKF2_GPS_P_NOISE` |
| 写参数 | `python3 SITL/脚本/fc_param.py set EKF2_GPS_P_NOISE 0.02` |
| 备份 | `python3 SITL/脚本/fc_param.py backup <文件>` |
| 恢复 | `python3 SITL/脚本/fc_param.py restore <备份> --yes` |
| 与默认比对 | 用 `~/PX4-Autopilot/build/px4_sitl_default/parameters.json` 全量比对 |

## 二、⚠️ 三个致命坑（都实测踩过，根因已定位）

### 坑 0 · **PX4 的 `INT32` 参数读回来是 `float`**

读 `PWM_AUX_FUNC5` 会得到 `411.0` 而不是 `411` ✗
⇒ 解析时**按 float 处理再转 int** ✓

### 坑 1 · **孤儿 NSH shell 会把 mavlink 线程卡死**

用 shell 交互时，如果**非正常退出**（比如 `Ctrl+C` 硬断），
会留下一个**孤儿 shell** ⇒ **mavlink 线程卡死** ⇒ **遥测全断** ✗

⇒ **后果**：**只能拔插 USB 才能恢复** ✗

**规矩**：用完 shell **必须正常退出** ✓

### 坑 2 · **`param select` 不带参数 ⇒ 空指针硬故障 ⇒ 复位**

敲一个**裸的 `param select`** 会让飞控**直接复位** ✗

**规矩**：**别敲裸的 `param select`** ✓

---

## 三、⚠️ 四条规矩

### 规矩 1 · **`param set` 会立刻落盘，没有反悔窗口**

⇒ **改之前先 `param show` 或 `backup` 备份** ✓

### 规矩 2 · **不要整机回灌画像**

参数之间**有耦合**（机型 → 混控器 → 电机映射 → 电调协议）
⇒ 整包回灌会把目标机上**本来就对的东西改错** ✗

⇒ **只抄"有意设置"** ✓

### 规矩 3 · **`CAL_*` 绝对不能抄**

**那是"该机最后一次的传感器标定值"** ⇒ 换机后**必须重新标定** ✗

### 规矩 4 · **板级默认不要抄**

不同型号的飞控（如 `PX4_FMU_V6C` vs `CUAV_7_NANO`）
**board defaults 本来就不同**（`COM_CPU_MAX` / `RC_CHAN_CNT` / `PWM_MAIN_*`）✗
⇒ **只抄有意设置** ✓

## 四、仿真里的零污染调参（推荐先在这做）

**【源码事实】** `test_k.sh` 支持通过环境变量注入参数：

```bash
PX4_PARAMS="EKF2_GPS_P_NOISE=0.02" bash scripts/test_k.sh hover_probe
```

**原理**：通过 `pxh` 的 **stdin FIFO** 注入 `param set` ✓

⚠️ **两个实现上的坑**（已解决，但值得记录）：

| 坑 | 说明 |
|---|---|
| FIFO 必须用 **`exec 3<> "$FIFO"`（读写）** 打开 | 用 `3>`（只写）会**阻塞等读者** ⇒ **死锁** ✗ |
| `test_k.sh` 每轮都要**重置 PX4 持久化状态** | 否则上一轮的参数会**残留** ⇒ 实验不干净 ✗ |

> **【经验/建议】这是本项目最好的一个实验手段** ✓
> 改一个参数 → 跑一次探针 → 看误差变化 ⇒ **因果清楚、零污染** ✓
> 事故 1 的那个判决实验就是这么做的 ✓

## 五、真飞控回来后的第一分钟

```bash
# ① 插上, 先只读 —— 这一步之前什么都别写
python3 SITL/脚本/fc_param.py dump > 现场参数_$(date +%Y%m%d_%H%M%S).txt

# ② 和上次的备份比对, 看有没有人动过
diff 上次备份.txt 现场参数.txt

# ③ 核对关键的几项 (机型/电池/高度基准/QNH)
```

> ⚠️ **【经验/建议】"先只读"很重要** ——
> `param set` 会**立刻落盘**，没有反悔窗口 ✗
