# 执行器参数（投放舵机）

> 投放机构的**控制链路**：代码 → `ManualControlSetpoint` → 飞控混控器 → AUX5 引脚 → 舵机

---

## 一、参数

**【源码事实】** 从 `硬件/PX4参数_RTK.params`：

| 参数 | 值 | 说明 |
|---|---|---|
| **`PWM_AUX_FUNC5`** | **411** | AUX5 输出功能 = **舵机** |
| **`PWM_AUX_MIN5`** | **900 µs** | 允许脉宽下限 |
| **`PWM_AUX_MAX5`** | **2100 µs** | 允许脉宽上限 |
| **`RC_MAP_AUX5`** | **Unassigned（0）** | ★ **必须解除遥控器占用** —— 见下 |

---

## 二、★ 为什么 `RC_MAP_AUX5` 必须解除

**【源码事实】** AUX5 走的是 PX4 的 **RC 输入路径**：
`ManualControlSetpoint` → RC 输入 → 混控器 → AUX5 引脚 ✓

⇒ 这意味着 **SBUS 接收机也在往这个通道写值**（更新率约 **111 Hz**）✗

**如果 `RC_MAP_AUX5` 还映射着遥控器的某个通道** ⇒
**遥控器和我们的程序会互相覆盖** ⇒ 舵机动不动 / 乱动 ✗

**处置**：

```bash
param set RC_MAP_AUX5 0        # Unassigned
param set PWM_AUX_FUNC5 411    # AUX5 = 舵机
```

然后重启飞控 ✓

---

## 三、代码侧的取值（与参数配套）

**【源码事实】** 代码里的映射是线性的：

```python
脉宽(µs) = 1500 + aux5 × 600
```

| 动作 | `aux5` | **脉宽** | 常量 |
|---|---|---|---|
| **锁定（待机）** | `0.0` | **1500 µs** | `AUX5_LOCK` |
| **投放第 1 瓶** | `+0.83333` | **2000 µs** | `AUX5_DROP` |
| **投放第 2 瓶** | `−0.83333` | **1000 µs** | `AUX5_DROP2` |
| 保持时长 | — | **1.0 s** | `AUX5_DROP_HOLD` |

> ⚠️ **两瓶方向相反**（2000 vs 1000）—— 与**两瓶镜像挂载**一致 ✓
> ⚠️ 1500 µs 落在这个范围内（900~2100）✓
> ⚠️ **投放脉冲保持 1.0 s 是必须的** —— 齿轮齿条有行程和摩擦，
> 发不够时间载荷可能**没完全脱开** ✗

---

## 四、频率：为什么是 200 Hz

| 项 | 值 |
|---|---|
| 我们的发布频率 | **200 Hz** |
| SBUS 接收机更新率 | ~**111 Hz** |

⇒ **必须发得比接收机快，才能"盖住"它的值** ✓
（否则接收机的手动信号会覆盖我们的值 ✗）

**【源码事实】** 代码里每 20 拍发一次（配合主循环），保证这个速率 ✓
