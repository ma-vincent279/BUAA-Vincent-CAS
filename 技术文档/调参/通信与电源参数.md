# 通信与电源参数

## 一、串口与通信

**【源码事实】** 从 `硬件/PX4参数_RTK.params`：

| 参数 | 值 | 说明 |
|---|---|---|
| **`SER_TEL2_BAUD`** | **921600** | ★ **机载电脑 DDS 链路的波特率** |
| **`SER_TEL1_BAUD`** | **57600** | 数传电台 |
| `GPS_1_CONFIG` | 201 | GPS 接在哪个口 |
| `MAV_0_CONFIG` | 101 | MAVLink 实例配置 |
| `MAV_0_MODE` | 0 | normal |
| `MAV_0_RATE` | 1200 | 数据流速率 |
| `MAV_SYS_ID` | 1 | 系统 ID |

### ★ `SER_TEL2_BAUD = 921600` 必须和启动命令对上

**【源码事实】** 机载侧的启动命令是：

```bash
MicroXRCEAgent serial --dev /dev/ttyTHS1 -b 921600
```

⇒ **波特率必须和参数一致** ✗ 不一致就**完全收不到数据**（而且不报错，静默失败）✗

**验证**：

```bash
ros2 topic hz /fmu/out/vehicle_local_position_v1    # 期望 ~50 Hz
```

### MAVLink 链路

| 项 | 值 |
|---|---|
| `MAV_0_CONFIG = 101` | 指定串口 |
| `MAV_0_MODE = 0` | 标准模式 |
| `MAV_0_RATE = 1200` | 1200 B/s |

## 二、电源与电池

**【源码事实】**

| 参数 | 真机值 | 默认 | 说明 |
|---|---|---|---|
| **`BAT1_N_CELLS`** | **6** | 0（自动）| **6S 电池** |
| `BAT1_CAPACITY` | **−1** | −1 | ⚠ **未设容量** ⇒ 无电量百分比 |
| `BAT1_A_PER_V` | **36.37** | 24 | 电流标定 |
| `BAT1_V_DIV` | **18** | 31 | 电压分压比 |
| `BAT1_I_CHANNEL` | −1 | — | 电流通道 |
| `BAT1_SOURCE` | 0 | — | 电源来源 |

### ⚠️ 为什么电源标定很重要（有血的教训）

**【实测数据】** 2026-09-30 那次**主供电线烧断坠机**：

| 时刻 | 电流 | 电压 |
|---|---|---|
| 正常飞行 | **41.7 A** | 22.92 V |
| 断裂瞬间 | **0.0 A** | **23.50 V**（开路）|

⇒ **排查完全靠电流！** ✗
⇒ 如果 `BAT1_A_PER_V` / `BAT1_V_DIV` **没标定准**，
**这类故障就看不出来** ✗

**另一个可测的前兆**：用**与电池模型无关的 V-I 回归斜率**看内阻趋势
—— 该趟是**唯一"末段内阻不降"**的（18.47 mΩ，比历史高约 5 mΩ）✓

⇒ **【经验/建议】起飞前必查：峰值电流 + 供电线接触 + 电池内阻趋势** ✓

## 四、安全与失效保护

| 参数 | 真机值 | 默认 | 说明 |
|---|---|---|---|
| `NAV_DLL_ACT` | **0** | 0 | 数据链丢失 → **不做动作** ✓ 否则会打断任务 |
| `NAV_RCL_ACT` | **2** | 2 | RC 丢失 → 动作 2 |
| **`COM_OF_LOSS_T`** | **10 s** | 1 s | ★ **有意放宽** —— 见下 |
| `COM_RC_IN_MODE` | **0** | 3 | 手动控制只认遥控器 |
| `COM_ARM_MAG_STR` | **2** | — | 磁力计检查 = **仅警告** ✓ |
| `COM_ARM_WO_GCS` | 0 | 0 | 无地面站时不允许解锁 |
| `SDLOG_MODE` | **0** | 0 | **随解锁开始记日志** ✓ |
| `SDLOG_PROFILE` | 1 | 1 | 日志内容档位 |

### ★ `COM_OF_LOSS_T = 10 s` 是**有意放宽**的

**为什么**：我们的任务节点在**投放段**会做计算密集的事（视觉 + 判据），
万一某一拍卡顿超过 1 s ⇒ **飞控会触发 failsafe 切走** ✗

放宽到 10 s ⇒ **让任务能跑完** ✓

> ⚠️ **代价**：真失联时**反应变慢** ✗ ⇒ 这是**有意的取舍** ✓
> **换机时一定要抄过去**，否则任务会莫名中断 ✓

### `SDLOG_MODE = 0`（随解锁开始记）

**【经验/建议】** 这个设置**对我们复盘很关键** ——
每次解锁就自动开日志 ⇒ **不会漏记** ✓
（我们有 **12 份实飞 `.ulg`** 做分析，全靠这个设置 ✓）
