# 估计器参数（EKF2）

> **EKF（扩展卡尔曼滤波）**是飞控回答"我现在到底在哪"的模块。
> 它融合 IMU / 气压计 / 磁罗盘 / GPS / RTK。
> **飞控报给机载电脑的位置，是 EKF 的估计值，不是真值** ✗
> ⇒ **EKF 参数直接决定"飞机认为自己在哪里"，也就直接决定投放精度** ✓

---

## 一、为什么要关心 EKF

**【实测数据】** 我们发现 **PX4 SITL 的 EKF 有约 8 cm 的水平偏差**（东向，系统性），
而且这个偏差是**飞行过程中长出来的**（`t=0` 时两套坐标是对齐的）✗

⇒ 这解释了"为什么仿真分数不能代表真实精度"（详见 [`../../技术全解.md`](../../技术全解.md) 第六部分）。

⇒ 而在**实机上**，EKF 的**参数配置**更是直接决定"飞机能不能停稳"
（见 [`参数事故记录.md`](参数事故记录.md) 事故 1）✓

## 三、★ `EKF2_GPS_P_NOISE = 0.5` 为什么是个问题

```
PX4 原文: "Measurement noise for GNSS position"    ← 单位 m
```

**它告诉 EKF："你收到的 GPS 位置，误差大约是 0.5 米。"** ✓

而**我们的 RTK 实测精度是 `0.000 m`**（`RTK fixed`、`eph = 0.000`）✗

⇒ 把精度 0 的传感器**当成精度 0.5 m 的普通 GPS** 去加权 ⇒
**卡尔曼增益被压小 10~25 倍** ⇒ 位置估计**主要靠惯性递推** ⇒ **缓慢漂移** ✗

**证据链**：

| 证据 | 值 |
|---|---|
| 12 份实飞日志的 `estimator_status.pos_horiz_accuracy` | **0.227~0.239 m**（几乎完全一致）|
| ⇒ 说明 | 这是**参数驱动的地板**，不是随机噪声 ✓ |
| = 0.5 m 噪声下的稳态协方差量级 | 吻合 ✓ |

**SITL 判决实验**（`0.5 → 0.02`）：**保持误差与游走速度都减半** ✓
（HOLD0 9.6→4.6 cm，HOLD1 26.0→15.4 cm）

**但**：**3 cm / 2.0 s 仍然达不到** ✗ ⇒ 这是**待做实机验证**的实验 ✓

> 📄 完整分析见 [`参数事故记录.md`](参数事故记录.md) 事故 1

## 四、其它几个值得理解的参数

### `EKF2_HGT_REF`（高度基准源）

| 值 | 含义 |
|---|---|
| **0** | **气压计** ← 我们用的 |
| 1 | GPS |
| 2 | 测距仪 |
| 3 | 视觉 |

⚠️ **【实测数据】** 有一趟因为 **`SENS_BARO_QNH` 是默认值**（标准大气压），
导致高度基准偏 **344 m** ⇒ **在地面就中止了** ✗
⇒ **高度这一路必须每次核对** ✓

### `EKF2_MAG_TYPE`（磁罗盘使用方式）

| 值 | 含义 |
|---|---|
| 0 | 自动 |
| 2 | 不用磁罗盘 |
| **5** | **仅用于初始化** ← 我们用的 |

**【经验/建议】为什么选 5**：机上装了**电机、电调、大电流线**，
**飞行中磁罗盘很容易被干扰** ✗
⇒ 只用它做**初始朝向**，之后靠 **GPS 航向 + 陀螺递推** ✓

### `EKF2_GPS_CTRL`（GPS 参与哪些估计）

**15 = 1+2+4+8** ⇒ **位置 + 速度 + 高度 + 双天线航向** 全都参与 ✓
（我们用 RTK，含双天线航向 ⇒ 所以是 15 而不是默认的 7）

---

## 五、调 EKF 参数的规矩

1. **不要为了"让仿真分数好看"去调 EKF** ✗ —— 仿真的 EKF 偏差是**仿真自身的问题**，
   调参数只会**掩盖它** ✓ 正确做法是**认清口径**（见 [`../../技术全解.md`](../../技术全解.md)）
2. **实机上要调就得有 before/after 证据** ✓（我们有 `hover_probe` 探针 + 判决实验流程）
3. **改之前先 `param show` 备份** ✓
4. **一次只改一个** ✓ 否则归因不出来
